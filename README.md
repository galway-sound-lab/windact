# WindACT

**Wind turbine noise annoyance and nuisance in Ireland.** Galway Sound Lab, University of Galway. Funded by SEAI (RD&D Grant 25/RDD/1354).

🌐 Project website: https://galway-sound-lab.github.io/windact
📦 Archived releases: <!-- Zenodo DOI badge goes here after the first release -->

## Repository layout

| Folder | Contents |
|---|---|
| `materials/` | Protocols, survey instruments, consent/PLS templates (after ethics approval) |
| `code/` | Analysis scripts (Python / R) |
| `data/` | **Pointers only.** Datasets are deposited on Zenodo or the University repository. |
| `*.md`, `_layouts/`, `assets/` | Website (GitHub Pages, Jekyll) |
